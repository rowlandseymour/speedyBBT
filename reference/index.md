# Package index

## Data sets

- [`darEsSalaam`](reference/darEsSalaam.md) : Comparative Judgment on
  Deprivation in Dar es Salaam, Tanzania
- [`forcedMarriage`](reference/forcedMarriage.md) : Forced Marriage in
  Nottinghamshire
- [`oxon.comparisons`](reference/oxon.comparisons.md) : Honour Based
  Abuse in Oxfordshire
- [`sy.comparisons`](reference/sy.comparisons.md) : FGM in South
  Yorkshire
- [`wimbledon`](reference/wimbledon.md) : Wimbledon Men's Singles
  Championship 2019

## Model fitting functions

- [`BBTm.ties()`](reference/BBTm.ties.md) : Bayesian inference for the
  Bradley-Terry model with ties
- [`BBTm()`](reference/BBTm.md) : Generalised Bradley-Terry model
- [`BBTm.with.formula()`](reference/BBTm.with.formula.md) : Bayesian
  Bradley–Terry model with comparison- and player-specific effect and
  formula
- [`speedyBBTm()`](reference/speedyBBTm.md) : Standard Bayesian
  Bradley-Terry model

## Helper functions

- [`comparisons_to_matrix()`](reference/comparisons_to_matrix.md) :
  Construct win matrix from comparisons
- [`parameter()`](reference/parameter.md) : Extract parameter draws from
  a model object
