# Package index

## Data sets

- [`darEsSalaam`](https://rowlandseymour.github.io/speedyBBT/reference/darEsSalaam.md)
  : Comparative Judgment on Deprivation in Dar es Salaam, Tanzania
- [`forcedMarriage`](https://rowlandseymour.github.io/speedyBBT/reference/forcedMarriage.md)
  : Forced Marriage in Nottinghamshire
- [`oxon.comparisons`](https://rowlandseymour.github.io/speedyBBT/reference/oxon.comparisons.md)
  : Honour Based Abuse in Oxfordshire
- [`sy.comparisons`](https://rowlandseymour.github.io/speedyBBT/reference/sy.comparisons.md)
  : FGM in South Yorkshire
- [`wimbledon`](https://rowlandseymour.github.io/speedyBBT/reference/wimbledon.md)
  : Wimbledon Men's Singles Championship 2019

## Model fitting functions

- [`BBTm.ties()`](https://rowlandseymour.github.io/speedyBBT/reference/BBTm.ties.md)
  : Bayesian inference for the Bradley-Terry model with ties
- [`BBTm()`](https://rowlandseymour.github.io/speedyBBT/reference/BBTm.md)
  : Generalised Bradley-Terry model
- [`speedyBBTm()`](https://rowlandseymour.github.io/speedyBBT/reference/speedyBBTm.md)
  : Standard Bayesian Bradley-Terry model

## Helper functions

- [`comparisons_to_matrix()`](https://rowlandseymour.github.io/speedyBBT/reference/comparisons_to_matrix.md)
  : Construct win matrix from comparisons
- [`construct.design.matrix.both.ways()`](https://rowlandseymour.github.io/speedyBBT/reference/construct.design.matrix.both.ways.md)

- [`construct.design.matrix.by.comparison()`](https://rowlandseymour.github.io/speedyBBT/reference/construct.design.matrix.by.comparison.md)

- [`construct.design.matrix()`](https://rowlandseymour.github.io/speedyBBT/reference/construct.design.matrix.md)
  : Construct the Bradley–Terry design matrix
- [`construct.generalised.design.matrix()`](https://rowlandseymour.github.io/speedyBBT/reference/construct.generalised.design.matrix.md)
  : Construct the generalised Bradley–Terry design matrix
- [`parameter()`](https://rowlandseymour.github.io/speedyBBT/reference/parameter.md)
  : Extract parameter draws from a model object
